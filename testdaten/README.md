# Testdaten (nur zum Ausprobieren)

Fiktive Unterlagen der **Nordlicht Gastro-Technik**: Kaffeevollautomaten **KV-400** (Büroküche) und **KV-800** (Theke mit Milchsystem). Kein echtes Produkt.

In der App: **Verwaltung** → anmelden → **Ordner wählen** und diesen Ordner `testdaten/` auswählen (oder den ganzen Unterordner).
